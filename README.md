# Plano Emagrecer

App para seguir o plano de emagrecimento: ementa semanal, registo diário com pontos (0–4), peso, lista de compras e regras.

**Abrir a app:** https://armendes97.github.io/new/

No iPhone: abrir o link no Safari → Partilhar → **Adicionar ao ecrã principal**. Funciona sem internet; os dados ficam guardados no telemóvel.

## Conteúdo

- `index.html`, `sw.js`, `manifest.json`, ícones, `lembretes.ics` — a app web (PWA).
- `ios/PlanoEmagrecer.swiftpm` — versão nativa em SwiftUI (precisa de Xcode num Mac ou do Swift Playgrounds num iPad).
